# 背景アートの依頼仕様（ノアの夜ふかしゲーム部 v1）

ノアは描き込みのあるアニメイラスト、現在の部屋は CSS の図形です。絵柄と光をそろえるため、**キャラクターを含まない夜の部屋**を2枚の画像で用意します。置けば `/stage` が自動で使い、無ければ今の図形の部屋のままです（コードの変更は不要）。

| ファイル | 内容 | 形式 |
|---|---|---|
| `public/models/room/background.png` | 部屋の奥（壁・窓・月・棚・ランプ）。キャラクターも机の手前も描かない | 1920×1080 PNG（不透明） |
| `public/models/room/desk.png` | ノアより手前に来る机の天板・キーボード・マグカップだけ。他は透明 | 1920×1080 PNG（透過） |

ファイル名は英数字のみ（サーバーはこのフォルダーの英数字名の `.png` しか配信しません）。

## 画面の配置（1920×1080、左上が原点）

描き込みを避ける・暗くしておく場所：

- **ゲーム盤面パネル**：x 36〜796、y 130〜890。上に不透明に近いパネルが重なるので、背景は暗く単純でよい（細部は見えない）。
- **番組タイトル**：上部中央 y 18〜130。明るい物を置かない。
- **目標の欄**：x 36〜796、y 926〜1056。
- **字幕の吹き出し**：x 830〜1170、y 650〜770 付近。
- **拾ったコメント**：右上 x 1454〜1884、y 130〜220 付近。

ノアの位置（背景に描かず、この位置に合う構図にする）：

- 体の範囲 x 1170〜1725、頭頂 y ≈ 265、あご y ≈ 660。肩から下は机の手前に隠れる。
- 机の天板の手前の縁は **y ≈ 790**、x 820〜1920。`desk.png` の天板はこの高さに合わせる。キーボードは天板中央（x 1060〜1500 付近）、マグカップは右寄り（x 1560〜1720 付近）。

## 絵柄と光

- ノアと同じ柔らかい塗りのアニメ背景。線は細く、彩度は控えめ。
- 夜。窓はノアの頭の後ろ左寄り（x 1060〜1540、y 170〜550 付近）に月と星。**窓側（画面左）から青い月明かり、画面右下のランプから暖色の光**。ノアの描画にも同じ向きの光を薄く乗せている（左が青、右が暖色、下側がやや暗い）。
- 奥の壁は落ち着いた紺〜紫。棚（本・小さな植物）は右上。
- 文字・ロゴ・既存作品のキャラクターや商標は入れない。

## 受け取ったら確認すること

1. 2枚を上のパスに置き、`npm run demo` の `/stage`（NOA BLOCKS）で、盤面・字幕・コメントが読めるか。
2. ノアの肩と机の縁が自然に重なるか（肩が浮いていない、机がノアの顔にかかっていない）。
3. 背景とノアの色味・明るさが別物に見えないか。
4. 素材の出典と利用条件を `THIRD_PARTY_NOTICES.md` に書く。
