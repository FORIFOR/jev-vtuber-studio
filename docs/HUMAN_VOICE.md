# 人間がノアの声で話す（NOA Studio Phase 3）

2026-10-19 にオペレーターが承認した設計です。

人間がノアとして話す番（Phase 1 の `voice: human`、F6）のときに、その声をどう出すかを `HUMAN_VOICE_MODE` で選びます。

| モード | 人の声の扱い | OBS の人間マイク | 字幕 | 遅れ |
|---|---|---|---|---|
| `passthrough`（既定） | そのまま流す（外部の変声アプリを手前に置いてもよい） | 開ける | なし | なし |
| `resynth` | 文字にしてから、**AI ノアと同じ音声合成（AivisSpeech コハク）**で読み直す | 閉じたまま（地声は流さない） | あり | 約3〜3.5秒（実測） |
| `rvc` | 外部の RVC アプリがコハクの声質に変えて、OBS の人間マイクに入れる | 開ける | なし | 0.2〜0.5秒（アプリによる） |

## 「コハクで読み直し」（`resynth`）

### 準備
1. **人間の声の出し方を選ぶ:** `/setup` の「人間がノアとして話す時の声」を「コハクで読み直し」にします。OBS の人間マイクのソースは要りません。
2. **whisper-server を起動する:** Phase 2 と同じものです（`docs/COLLAB.md`）。
3. **マイクを聞かせておく:** Studio の「声を聞くページ（通話・中の人）」を開きます。「中の人のマイク」で実際のマイクを選び、「聞き始める」を押しておきます。BlackHole は選ばないでください（警告が出ます）。

### 流れ
- 人間が話す番の間だけ、マイクの声を区切りごとに文字にします（`POST /api/human/segment`）。
  - AI が話す番の間に届いた音声は、文字にせずに捨てます。
- **確認:** 文字にした言葉は、ローカルの個人情報・乗っ取りのチェックだけを通します。ゲートは通しません（オペレーター決定 2026-10-19）。
  - 引っかかった文は読み上げず、「読み上げませんでした」と Studio に通知します。通知に本文は含めません。
- **読み上げ:** チェックを通った文は、届いた順に AI ノアと同じ音声合成で読み上げます。
  - 次の文は、前の文を再生している間に用意します。
  - 字幕、口の動き、Discord への声（OBS のモニター経由）は、AI の発話と同じ経路です。
- **AI に戻すと（F6）:** 列に残った文は捨て、再生中の文はそこで止めます。
  - AI の最初の発話には、人間が話した直近6文を渡します（`humanSaid`）。AI はその流れを踏まえて続け、同じことを繰り返しません。

### 遅れ（2026-10-19 にこの Mac で実測）
- 4秒ほどの文で、音声認識が 1.15 秒、コハクの読み上げが 1.6 秒でした。
- 話し終わりの判定（0.6 秒）を足すと、話し終えてから声が出るまで約 3.4 秒です。
- 抑揚と間は AI ノアの読み方になります。テンポの速い掛け合いには向きません。

## RVC（`rvc`、Phase 3b）

Studio は OBS の人間マイクの入力を開けたり閉じたりするだけです。声質の変換は外部のアプリが行います。

1. **学習用の音声を作る:**
   ```sh
   node scripts/kohaku-dataset.mjs --text <文の一覧.txt> --out data/kohaku-dataset --limit 600
   ```
   - 1行ずつ、Studio と同じ AivisSpeech のコハク（`AIVIS_STYLE`）で WAV にします。
   - `transcripts.txt` と、音声モデルのライセンス文書（`LICENSE-voice-model.md`）も一緒に書き出します。
   - 文の一覧は、ライセンスを確認したものを使ってください。
2. **RVC のモデルを学習する:** Studio の外で、RVC の学習ツールを使います。
3. **変換アプリを用意する:** リアルタイム変換アプリ（例：Apple Silicon 対応の w-okada voice-changer クライアント）で、マイクをコハクの声質に変えます。出力は OBS の人間マイクのソースが受ける入力（BlackHole など）にします。
4. **Studio を設定する:** `/setup` で「RVC」を選び、そのソースを「人間マイクのOBSソース名」にします。

## ライセンス（コハクの音声モデル：ACML 1.0）

- **認められていること:** 派生モデルの作成と配布は認められています。配布するときは、ライセンス文書を必ず一緒に付けます。
- **禁止されていること:**
  - 話者・制作者・公式と誤解させる使い方
  - 話者の品位を下げる使い方
  - 攻撃・政治・詐欺・反社会的な目的での利用
- **人間が話す中身:** ゲートを通らないので、この禁止事項を守る責任はオペレーターにあります。
- **クレジット:** 配信のクレジット（`AIVIS_CREDIT`：AivisSpeech：コハク（オズチャット））はそのまま出し続けます。

## まだ確かめていないこと
- 実際のマイクでの区切りの感度、字幕と口の動きの見え方、Discord の相手への聞こえ方
- RVC の学習と変換の品質（Studio の外の作業）
