# rc.2 → rc.3 更新手順

既存の配信を停止してから、新しいフォルダへ展開します。使用中の旧版へ上書きしません。起動・デモのコマンドは従来どおりです。秘密の`data/`を移す場合は非公開のまま引き継ぎ、Gitやチャットへ添付しないでください。旧版と同時に同じdataディレクトリを使いません。

遠隔操作は初期状態で無効です。使わない場合も、OBS専用ソースを「OBSに専用シーンを作る」で更新し、実試聴をやり直してください。rc.3はOBSの再生元を別識別します。起動ごとに識別子が変わるため、外出前の再起動後もソースを更新します。

スマホから開始する場合は[REMOTE.md](REMOTE.md)に沿ってTailscale、専用ゲートウェイ、録画確認、8時間の開始許可を設定してください。設定済みキーの保存方法は変更していません。遠隔許可や試聴済み状態は再起動時に引き継がれません。

旧版へ戻すとremote-control.jsonは読み込まれません。Tailscale Serveの転送設定は残るため、不要な転送も別途停止してください。再配信を自動的に開始することはありません。

## 過去の更新説明

# rc.1 → rc.2 更新手順

## まず停止する

旧版の自動運転を止め、OBSとYouTube側でも配信終了を確認します。起動中のフォルダへ上書きしないでください。`data/`を共有して新旧を同時に起動しないでください。

## 新しいフォルダへ展開

`jev-vtuber-studio-v0.2.0-rc.2.zip`を新しいフォルダへ展開します。`.gitignore`と`.npmignore`も含まれています。Node.js 22.12以降は別途必要です。

保存済み設定を引き継ぐ場合だけ、旧版の`data/`を**非公開のまま**新しいフォルダへコピーします。APIキー・OAuthトークン・使用量が入るため、GitHubやチャットへ添付しないでください。使用量ファイルを消して日次制限を回避しないでください。`.env`で設定していた場合も必要なものだけ私的に移してください。`DATA_DIR`を指定していた場合はその配置を確認します。

設定形式は変更していません。モデル、VOICEVOX、OBSの導入はそのまま利用します。`node_modules/`や`dist/`はコピーしません。YouTubeの追加gRPCライブラリが必要な場合のみ、新フォルダで`npm run setup:youtube`を実行します（取得には通信が必要）。

## 再確認する

```sh
npm start
```

ターミナルのControl URLを開き、接続設定から実試聴と聴取確認をやり直してください。API未使用で画面だけを見る場合は`npm run demo`です。デモは固定台本で、実モデルの品質確認ではありません。

ローカルで、コメント返答、次の話題、通常終了、緊急停止を確認してから録画・限定公開へ進みます。更新だけでYouTube配信が自動的に始まることはありません。

## Gitへ登録する場合

まず`git status --short --untracked-files=all`で`.env`と`data/`が追加対象にないことを確認してください。すでに追跡済みの秘密ファイルは`.gitignore`だけでは除外されません。カスタムの`DATA_DIR`はチェックアウトの外へ置くか、除外規則を明示してください。今回の配布物に実キーは同梱していません。
