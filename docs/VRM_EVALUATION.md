### 検査で見つかった問題と修正

- idleの頭・首を未制御にせず、基準回転トラックを明示して途中停止後の姿勢復帰を保証。
- 初回描画前や音声中断時にも古い反応を再生しないよう、停止した反応IDを抑止し、口を閉じる状態を保持。
- 戻る・進むのキャッシュ復帰でWebGLを破棄しないよう修正。通常のページ離脱では資源を解放。
- 初回の動的検査は24/33成功に留まり、首振り・手振り中断・驚き中断で毛先 `J_Sec_Hair3_03` が衝突球の間の別の平衡位置に留まった。人体は復帰しており、髪の問題だった。
- 衝突球を縮める案は採用せず、毛先 `J_Sec_Hair1_03` から `4_03` の4関節にのみ `gravityPower=0.02` の弱い下向きの力を追加。元VRMのバイト列、全衝突球の半径・位置、他のばね設定は保持。姿勢の強制リセットや検査対象の除外はしていない。
- 修正後に33ケースすべて再実行。衝突球・他の設定が不変であることと、補正の二重適用でも値が変わらないことも検査した。

**判定: 3D統合のコード・アセット・数値動作検査は合格。本番配信の視聴覚検収は未完了。**

## 外観・動作評価の区別

移植元AIRoid_3Dでは、同一ハッシュの4.86モデルについて顎・肩の実メッシュ検査とBlenderによる正面・斜め・横・笑顔・開口・首振り・手振りのオフライン画像確認が行われている。
本変更のハッシュ検査はそのモデルを変更せず移植したことを確認するが、**Jevのブラウザ描画がBlenderと同じに見えることは保証しない**。

今回の自動検査では、次の項目は評価できない。

- Jev配信画面での読み込み完了、表示サイズ、カメラの収まり、明るさ、透過合成。
- WebGL描画時のテクスチャ・材質・顎輪郭の最終的な見え方。
- 実音声の再生タイミングと口パクの同期、コメント読み上げ時の閉口。
- 髪の見た目としての自然さ、服と肌の動的な貫通、表情混合時の見た目の破綻。数値復帰は上記の条件に限り検証済み。
- OBS上でのフレームレート、音声所有権、再接続、長時間稼働。

ブラウザアクセス制限を迂回する検証は行わない。スクリーンショットや実描画の確認ができない状態を「表示確認済み」と記載しない。
トップVTuberを上回る品質や「90%以上」という数値は、評価基準と比較条件が未定義のため主張しない。

## 再現コマンド

```sh
node --test test/vrm-assets.test.mjs
node --test test/avatar-mode.test.mjs test/avatar-mode-assets.test.mjs test/vrm-serving.test.mjs
npm run release:check
npm run check:avatar
```

`check:avatar` と `evaluate:*` は [VRM.md](VRM.md) の固定ビルドツールを使う開発用コマンド。通常起動や基本の回帰検査にはインストール不要。実ブラウザ・OBSの受入検査は通常の許可された環境で別途必要。
