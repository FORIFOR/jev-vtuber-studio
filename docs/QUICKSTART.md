# 最短手順（1ページ）

詳しい説明は [初回設定](SETUP.md)。ここは「今日中に一度、ローカルで声を出すまで」の最短経路だけ。

1. **起動**: Node 22.12 以上で `npm start`。表示された Control URL（`/setup#admin=…`）を開く。URL は他人に渡さない。
2. **デモを見る**: 鍵なしで「デモを開く」。画面と字幕が動けば、Studio 自体は動いている。
3. **AI と声をつなぐ**（設定 02）: 会話モデル（Ollama など）と VOICEVOX を起動し、「設定を保存して、モデルと声を検出」。一覧から選んで保存。Jev の鍵を保存。
4. **試聴する**（設定 03）: 利用料の確認にチェックして「実APIで試聴」。再生して、耳で聞いてから「聞こえた」を押す。
5. **準備状況を見る**（設定の先頭）: 「いま確認する」で ✗ が残っていれば、その行の「開く」から直す。録画の確認だけは人が行う。
6. **OBS**（設定 04 → スタジオ）: OBS の WebSocket を有効にして URL とパスワードを保存。スタジオで「OBSに専用シーンを作る」。
7. **番組を始める**: スタジオの「配信を始める」。外部配信は OBS 側で、別途あなたが開始する。

広告を入れるとき: スタジオの「広告」タブ。「広告枠を表示する」をオンにすると、登録した広告が順番に出て、なければ「広告募集中」が出る。「＋ 広告を追加」で画像・動画・PDF を入れる。

ゲーム企画のとき: Vampire Survivors は設定「ゲーム配信」で操作役のフォルダを指定。スマブラSP は右上「Switch接続」で機器を選び、テスト録画で映像と音を確かめてから。

キャラクターを替えるとき: 名前・番組名・話し方は設定 01。OBS プロファイル名・BGM ソース名・Twitch チャンネルは `config/character.json`。企画の言葉は設定「企画の編集」。雑談の場面（ゲーム前の小話）に自分のキャラ向けの物語を使うなら `data/lobby-scenes.json` に `config/lobby-scenes.json` と同じ形で置く（置かなければ組み込みを使う）。
