# Jev の判断表示

Vampire Survivors の横長ゲーム画面に、実際のコントローラログから小さな判断カードを表示します。ゲーム画面の下、字幕の上に置き、顔と広告枠は覆いません。表示中だけ参加案内を隠します。

## 表示するもの

- Jev が選択し、ゲームブリッジが入力を受け付けた項目または移動方向。
- Jev が返した候補の選択分布、上位3件まで。生存率・正解率ではなく、表示値の合計が100%とは限りません。
- 判断前の観測に記録されたHPの割合。入力後の回復を意味しません。

ログに自然言語の判断理由はありません。「囲まれないため」「進化を優先した」などの理由は補いません。「入力受付済み」はブリッジの受付確認であり、アイテム取得や生存成功の証明ではありません。

## 表示の制限

- 入力未適用、失敗、合成、未知の候補名、不正な分布は表示しません。
- 新しい有効なログだけを使い、起動・再接続時に過去の判断を再生しません。
- 最大2秒で消えます。通常移動は最低8秒間隔、レベルアップは優先します。
- 停止、ゲームの切り替え、接続断で直ちに隠します。状態スナップショットには判断を保存しません。
- タイムスタンプはログの更新時刻と経過時間からの推定です。フレーム単位の同期を保証しません。
- 横長ゲーム画面の通常ソース、または分割構成のoverlayレイヤーが対象です。縦配信や雑談画面には表示しません。

新たなJev呼び出しは行いません。既存の読み取り専用ログフィードを利用し、公開イベントには固定形式の許可済み項目だけを渡します。プロンプト、診断情報、任意の自由文は渡しません。

## Shorts の制作

元録画と同じラウンドのログを使い、メニューが閉じる場面など複数の目印で時間を照合します。装備追加は次の観測でも確認します。移動は次の判断までが短いため、長い映像の結果を単一判断の成果と扱いません。

カード、字幕、解説音声、静止・拡大などの編集を加えた場合は、その事実を説明欄や画面に明記します。公開用動画を作ることと、外部サイトへ投稿することは別の操作です。
