# 広告・スポンサー表示

Studio右側の「広告・スポンサー」で、配信画面に静止した募集案内またはスポンサー紹介を表示する。OBSのStageに描画するため、同じ映像を送るYouTubeとTwitchの両方へ反映される。設定の保存だけでは番組・OBS配信は開始しない。

## 複数の広告（広告ライブラリ）

Studio の「広告」タブで、受け取った広告を何件でも（20 件まで）登録し、順番・表示秒数・オンオフを個別に決められる。保存先は `data/ads.json` とメディアの `data/ad-media/`（内容のハッシュ名）。

- **スイッチは一つ**：「広告枠を表示する」がオンのとき、有効な広告を上から順に、各自の秒数（10〜600 秒、既定 60 秒）ずつ巡回する。有効な広告が一つもなければ、下の「広告がないときの案内」（既定は「広告募集中」）が出る。スイッチがオフなら何も出ない。
- **受け付けるファイル**：画像 PNG / JPEG / WebP（2 MiB まで、静止画のみ）、動画 MP4 / WebM（64 MiB まで。音は既定でオフ、広告ごとに「音を出す」を選べる）、PDF（macOS 標準の画像変換で 1 ページ目を PNG にする。macOS 以外では画像に書き出してから）。ファイルなし・見出しだけの文字広告も可。
- **追加の手順**：「＋ 広告を追加」→ ファイルを選ぶ → 必要なら見出し・メッセージ・URL・秒数 → 「追加して反映」。アップロード後に一覧へ保存され、スイッチがオンなら次の切り替えから配信画面に出る。一覧の「表示する」「表示秒数」「↑↓」「削除」も押した時点で保存・反映される。
- **安全側の扱い**：ファイルは宣言された種類と中身を照合し（動画は先頭バイト、画像は既存の厳密な検査）、どの広告も画面には「広告 / PR」が付く。メディアは閲覧トークン付きの同一オリジン経路（`/api/sponsor/image/<id>`）だけから取得し、外部 URL は読まない。一覧の保存は版番号つきで、別の画面との競合は上書きしない。参照されなくなったメディアは 1 時間後の保存時に削除する。
- **動画の再生**：OBS のブラウザソースで `<video>` を再生する。音ありの広告はノアの声と同じ音声経路に混ざるため、音量とタイミングはテスト録画で確認する。動画の実再生（OBS の CEF での MP4/WebM 対応）はこの環境では未検証。

## 使い方（広告がないときの案内）

1. 「広告・スポンサーを募集」または「企業・サービスの広告を掲載」を選ぶ。
2. 見出し、紹介文、必要ならHTTPSの案内先URLと画像を指定する。
3. プレビューで内容を確認し、「配信画面に表示する」を有効にして「保存して反映」を押す。
4. 取り下げたいときは「今すぐ非表示」を使う。配信中も表示内容を変更できる。

「広告募集の案内を入力」で「広告募集中」「このスペースに広告を掲載できます」を下書きに入力できる。現在の案内先URLは維持し、画像は下書きから外す。保存までは配信画面を変更しない。

募集モードは、広告掲載や協賛の相談を募る案内。契約済みスポンサーがあるようには表示しない。実案件を表示するモードでは「広告 / PR」の表示を常に付ける。

画像は静止PNG・JPEG・WebP、2MiB以下。SVG、GIF、アニメーションは受け付けない。広告枠は白背景の16:9で、横配信では480×270px（2Dの外部ゲーム配信・NOA BLOCKS・内蔵ゲームは416×234px）、縦配信では480×270px（ゲーム中は448×252px）。募集文は上下左右中央に配置する。画像は枠全体に縦横比を維持して表示し、切り取ったり引き伸ばしたりしない。1920×1080pxまたは1280×720pxを推奨する。別の比率は白い余白が付く。

画像があるときは見出し・本文・URLを画像に重ねず、募集／広告・PRラベルだけを枠のすぐ上に残す。画像の読込失敗時は文字表示へ戻る。画像がないときは見出し・紹介文・URLを中央に表示し、長い文章は省略する。画像・本文・URLは静止表示し、音やスクロールを付けない。ゲーム画面と字幕を避け、Vampireの選択コメントは右下に2行で表示して顔と広告を避ける。映像内に表示したURLは視聴者がクリックできないので、各配信の説明欄・プロフィールにも案内先を掲載する。

配信画面の更新は既存のイベント接続を使い、広告配信会社のスクリプト・外部画像・トラッキングは読み込まない。画像はローカルに保存する。動画CM、音声広告、自動読み上げ、複数広告の自動巡回、広告販売・決済はこの機能に含まない。

## 実案件を掲載するとき

画面の「広告 / PR」に加え、YouTubeの有料プロモーション申告、TwitchのBranded Content設定を行う。募集用表示の保存がこれらの設定を自動変更することはない。案件の種類や表示方法が各サービスで認められることを掲載前に確認する。

- [YouTubeのブランドコンテンツ規則](https://support.google.com/youtube/answer/17596007)
- [YouTubeの広告埋め込み規則](https://support.google.com/youtube/answer/3364658?hl=en)
- [Twitchのブランドコンテンツ表示](https://help.twitch.tv/s/article/branded-content-policy)
- [Twitch利用規約](https://www.twitch.tv/p/terms-of-service)

## 保存とアクセス

設定と画像はGit管理対象外の `data/` に保存する。管理認証がある端末だけが保存・変更でき、視聴用認証では表示の取得だけができる。コメントやAIの返答から広告設定を変更する経路はない。

保存には現在の版番号を使い、別のStudioで先に変更されていた場合は上書きせず競合を知らせる。画像と設定の保存に失敗した場合は直前の状態を維持する。通常の設定変更・表示切り替えにサーバーやOBSの再起動は不要。
