# rc.5：進行投影・繰り返し抑制・番組改修

## 対象と根拠

この会話のrc.4配布ZIPを作業用コピーへ展開して修正。ユーザーが貼った02:56:27〜02:57:46 JSTの記録は申告情報で、稼働PCのメモリ、Ollamaログ、OBS録画をこちらから取得したものではない。

配布済みrc.4の`Director.context()`には、先読み中のopening完了を仮定してautonomousへ進む分岐が既に存在した。また「神部屋」の固定例文は同ZIPに含まれていない。したがって、申告されたサーバーの直接原因を同ZIPだけから断定しない。手元で加えたプロンプト・保存済み人格・実際の稼働版が影響した可能性は残る。

一方、同ZIPで確認した問題は次の2つ。

- projectedBeatは増えるが、angleは未投影の古いbeatから選ばれていた。beat2から次のbeat3を準備したとき、角度がfirstのまま。
- context.demoに固定台本があり、そのままliveの生成リクエストのJSONに含まれる。「真似しない」という指示だけでは例文を除去できていなかった。

`programme-rc4-observations.json`は上記のローカル観測値。実Ollamaの推論・聴取試験ではない。

## 修正内容

### 進行の投影と実際の完了を分離

`src/director.mjs`にcursor、progressKey、committed serialを導入。準備時に、現在再生中のターンが完了した後のbeat/goalを同じ規則で投影する。投影だけでopened、beat、既聴履歴を変更しない。現在の課題と異なる準備済み音声は、送出前に破棄する。openingが既に完了していれば、もう一つのopeningは送出しない。正規の一つの完了が二重にcommitされないようにした。

カードの最終段階では次のカードを先回り生成せず、完了ACKを待って新しいカードから生成する。1箇所の遷移で少し待つ可能性と引き換えに、古い課題の先読みを生成して捨てるのを避ける。取消・単一生成枠・単一音声所有者の制御は保持。

### 台詞例を本番入力から除去

`src/providers.mjs`はdemoを分離してからliveContextをシリアライズする。Ollama/互換/Geminiそれぞれで、固定台本のセンチネルがHTTP要求に含まれないことを検査。デモは固定台本として明記し、本番品質の例としない。

`CHARACTER_PERSONA`等の保存済み設定は自動で消さない。設定画面に「企画雑談向けの話し方に戻す」を追加し、確認後に入力欄だけを変更。さらに保存と試聴が必要。独自のproviders.mjsやプロンプトの固定台詞は別途差分確認が必要。

### 言い換えループを検査

ローカルのNFKC正規化＋文字3-gram類似度（0.82以上）と、繰り返す導入のパターンを確認する。直接の視聴者返答・締めでは適切な要約を許容し、機械的にすべて拒否しない。

出力検査の同じJevリクエストへnovel/progressを追加。直近の発言・今回のgoalに照らし、言い換えだけか、課題を進めたかを問う。安全検査は維持。これらの確率0.7の初期閾値は未校正で、意味的一致や安全の保証ではない。

繰り返し/課題未達に限り、一度だけ理由付きで生成し直す。拒否された全文は修正プロンプトへ再投入しない。2案とも課題未達なら`content_stalled`で自動運転を停止し、未審査のつなぎ台詞を流さない。通常のAPIエラーは既存の回数上限とバックオフ、安全の拒否は単なる「文体修正」扱いにしない。

修正生成は追加のLLM/Jev料金を使い得る。修正最大1回であり、回数・失敗をメトリクスへ残す。使い続けることでモデル自体が学習する実装ではない。

### 結末のある3企画と画面

`config/programmes.json`に3企画×27段階、表示用の短い問い、デモ台詞を追加。標準は15分上限で、企画完了なら早く終了。内容を循環させて尺を埋めない。

画面には企画名・現在の幕・短い問い・完了段階を表示。任意の縦型配置は`layout=vertical`で選べるが、OBS/YouTubeの設定や遠隔接続の実確認は行わない。

進行完了のメタデータをローカル監査へ記録し、管理画面からJSON取得可能。録画の見返し補助であって、面白さ・視聴回数の自動推定ではない。番組の代表3案のCLI出力も追加。

## 回帰検査

追加27件。3番組の有限完走、8ターン中の導入回数、投影の非破壊性、二重完了、古いカーソルの送出拒否、境界の先読み抑制、コメント返答時のbeat保持、本番へのdemo非送信、類似文と新規具体例、修正上限と停止、途中中断、Jev同一要求の質問、設定・レポートの権限を含む。

従来170件のうち、初期時間の期待値を30分から15分へ更新。300ターン負荷試験は、循環を試す目的があるため、試験内だけfinite=falseを明記。製品既定の有限停止は新規3本の完走試験で別に検査。旧版の音声・コメント・遠隔・秘密除外試験を削除していない。

配布検証の過程でPythonの一時バイトコードがnpm選択対象になったため、`.npmignore`と配布側の拒否規則へ`__pycache__`/pyc/pyoを追加。明示的なscripts/ディレクトリ指定が除外より優先されたため、配布対象もscripts/*.mjsとscripts/*.pyへ限定。最終ZIPでは含まれないことを検査した。
