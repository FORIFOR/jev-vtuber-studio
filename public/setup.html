    01

    どんな番組にしますか？

    初期キャラクター「ノア」でそのまま始められます。

    一つの企画を3つの観点で進めます。話し切ったら自動で締め、同じ内容で配信時間を埋めません。

    以前の固定台詞が話し方に残っている場合に使用します。保存するまでは設定を変更しません。

    01b

    ゲーム配信

    ゲームのない企画です。ゲーム企画を選ぶと、ここにそのゲームの取り込み方と設定が出ます。

    映像と音はSwitchのキャプチャー機器から取り込みます。機器の選択・プレビュー・テスト録画は Switch接続 で行い、番組を始めるとその機器がゲーム枠に映ります。

    AIが操作するゲームは、番組の開始と同時にこのフォルダの操作役を起動します。

    01c

    企画の編集

    企画名・問い・各段階の課題と見本の台詞を書き換えられます。保存前に、組み込みの企画と同じ基準（見本は2文・180文字以内、課題は重複なし、段階の数は固定）で検証します。保存先は data/programmes/ で、次の番組開始から使われます。

      02

      AIと声を接続

      キーはこのPCの非公開設定ファイルへ保存されます。ブラウザへ再表示しません。

      キャラクターの返答音声

      Supertonic 3を別途起動します。v1/v2は日本語用に採用しません。公式開発は終了しているため、固定版をローカルで利用します。導入は docs/COMMENT_REPLY.md を参照してください。

      AivisSpeech Engineを別途起動します（初回起動時はモデルをダウンロードします）。ACML-NCのモデルは営利目的で利用できません。モデルの利用規約を確認してください。

      macOSでは:5000をAirPlayレシーバーが使うため:5055を推奨します。APIサーバーは0.0.0.0で待ち受けるため、ファイアウォールで外部から遮断し、設定で origins: [] にしてください。あみたろ／小春音アミ系のモデルは画面と配信説明へのクレジット表記が必要です。JVNVモデルはCC BY-SAです。

      APIキーは会話モデル設定の GEMINI_API_KEY を使います。有料：発話1時間あたり約$0.81（Flash）／約$0.54（Flash-Lite）、2027年1月から倍額。上限額に達すると発話を保留し、別の声へは切り替えません。無料枠では入力がGoogleの製品改善に使われます。笑い・息などの反応音は、録音が無い場合、同じ声の音声タグで生成します。

      話し方の演出

      反応音と定型フレーズは npm run voice:library で登録します。有効にする前に npm run voice:bench で効果を測ってください。演出は承認済みの文章を変えず、別の声へ切り替えません。

      コメントを読む声

      読み上げ中に回答を準備します。全コメントは読まず、採用・引用可と判定された短いコメントだけを対象にします。投稿者名・URLは読みません。音声をAIへ再入力しません。

      まだローカルエンジンがない場合

      OllamaまたはLM Studioと、VOICEVOX Engineを別途導入して起動します。モデルのダウンロードは時間とディスク容量を使います。この画面は許可なく導入しません。

      導入手順と使用できる接続方式は配布物の docs/SETUP.md を参照してください。

      03

      公開する前に、ひとこと試聴

      文章生成 → ローカル判定 → 選んだ返答音声と、コメント用VOICEVOXを実際に合成します。両方を試聴してください。生成が失敗したら、接続成功とは表示しません。

        再生完了の通知だけでは、実際に音が聞こえたことの証明にはなりません。耳で確認してください。

        04

        YouTubeとOBSへ

        試聴だけなら未設定で構いません。公開配信の開始は、スタジオでの別操作です。

        ストリーミング用の追加パッケージは「npm run setup:youtube」で導入します。未導入時はポーリングへ移行し、その状態を表示します。非公開情報などでOAuthが必要な場合はdocs/SETUP.mdを参照してください。

        ストリームキーはOBSにのみ設定してください。音声・画像の利用条件とクレジット、配信の公開範囲は配信者が確認します。AIによる自動配信であることはステージに常時表示します。

        05

        スマホから開始する

        初回はPCで npm run remote:setup を実行し、Tailscale Serveを設定します。設定変更・再起動後は再確認が必要です。

        遠隔設定を確認してください。

        OBSの専用ソースで実音声を再生・録画確認し、ローカル自動運転を停止してください。OBS・Studio・モデル・音声エンジンは起動したままにします。

        許可を取り消しても、進行中の番組は別途「停止」が必要です。スマホに管理キーや配信キーは渡しません。

        06

        配信ログ・分析レポート

        過去の配信で何を話し、どう進んだか、発言の重複がなかったかを分析します。

        設定はローカルに保存。勝手に配信を開始しません。
